SQL方言转换效果演示

MySQL DDL 一键转 PostgreSQL，包括数据类型自动映射

🐬 MySQL
-- MySQL DDL
CREATE TABLE users (
  id INT AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE,
  age TINYINT UNSIGNED,
  salary DECIMAL(10, 2),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
) ENGINE=InnoDB;

INSERT INTO users (name, email, age)
  VALUES ('Alice', 'alice@test.com', 28);
➡️
🐘 PostgreSQL
-- PostgreSQL DDL
CREATE TABLE users (
  id SERIAL,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE,
  age SMALLINT,
  salary DECIMAL(10, 2),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
);

INSERT INTO users (name, email, age)
  VALUES ('Alice', 'alice@test.com', 28);

✨ AUTO_INCREMENT ↔ SERIAL | TINYINT UNSIGNED ↔ SMALLINT | DATETIME ↔ TIMESTAMP | 50+类型映射自动完成
