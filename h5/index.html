核心功能

一站式数据库管理平台

覆盖数据库管理全生命周期，从连接到分析，从对比到同步

🤖

AI Agent 智能助手

内置 Agent/Skill/MCP 工具体系，支持自然语言生成 SQL、SQL解释、性能优化。可自定义 Agent 行为、绑定工具和数据源权限。

🧩

Skill 技能模板

可复用的 AI 提示词模板，定义特定任务的执行方式。支持版本管理、导入导出、AI 辅助生成。

🔧

MCP 工具生态

11+ 内置工具类别：数据源管理、查询执行、Schema 信息、结构对比、服务器监控、慢 SQL 分析等。

📊

语义层引擎

内置 OLAP 语义层，支持 Cube 数据建模、度量和维度定义、模型关联。让非技术人员也能理解业务数据。

💬

IM Bot 集成

支持钉钉、飞书、企业微信机器人接入，在即时通讯工具中直接与 AI 对话，完成数据查询、分析等任务。

📈

慢 SQL 监控

实时捕获慢查询，历史 Top SQL 分析，执行计划解读，索引优化建议。帮助 DBA 快速定位性能瓶颈。

🏥

数据库巡检

自动采集数据库健康指标，AI 分析生成巡检报告。涵盖连接数、缓存命中率、锁等待、空间使用等关键维度。

📁

文件管理

支持本地存储和 S3 对象存储，提供文件上传下载、目录管理、批量操作。可作为 SQL 脚本、报表的统一管理中心。

📝

脚本管理

SQL 树形目录管理 SQL 脚本，支持自动保存、版本历史、快速搜索。团队共享常用脚本，提升协作效率。

📋

报表面板

自定义 SQL 报表，支持多种图表类型。可分类管理、定时刷新、导出分享，打造数据可视化看板。
